# Drum Machine 🥁

Интерактивная музыкальная драм-машина, воспроизводящая различные звуковые сэмплы при клике мышкой или нажатии соответствующих клавиш на клавиатуре. Проект выполнен в рамках практического освоения фронтенд-разработки.

## 🚀 Демонстрация
[Посмотреть проект в действии](https://github.io)

## 🛠 Технологический стек
* **JavaScript (ES6+)** — обработка событий клавиатуры (`keydown`), управление аудио-элементами HTML5 Audio API.
* **HTML5 / CSS3** — семантическая разметка пэдов, стилизация интерфейса и адаптивная сетка (Grid/Flexbox).
* **React / Чистый JS** — управление состоянием активных звуков и отображением названия текущего трека на дисплее.

## 💡 Реализованный функционал
* **Двойное управление:** Звуки воспроизводятся как по клику на интерактивные пэды, так и при нажатии горячих клавиш (Q, W, E, A, S, D, Z, X, C).
* **Информационный дисплей:** При активации пэда на экране мгновенно отображается название проигрываемого звукового сэмпла.
* **Адаптивность:** Музыкальная панель подстраивается под размеры экранов планшетов и мобильных телефонов для удобного тач-управления.
